# 🧠 Algorithm Study

Python으로 알고리즘 문제를 풀고 풀이 과정을 기록하는 저장소입니다.

주로 백준 문제를 풀면서 Python 문법과 문제 해결 방법을 익히고,  
이후 프로그래머스 문제도 함께 풀어볼 예정입니다.

---

## 🎯 목표

- 문제를 직접 분석하고 해결하는 습관 만들기
- Python 문법을 문제 풀이에 자연스럽게 적용하기
- 자료구조와 알고리즘의 기본 원리 이해하기
- 다양한 풀이 방법과 시간복잡도 생각해보기
- 코딩테스트 문제 풀이에 익숙해지기

---

## ✏️ 문제 풀이

정답 코드를 바로 보기보다 직접 풀이 방법을 생각해보는 것을 우선합니다.

`문제 이해 → 입력/출력 확인 → 풀이 방법 생각 → 구현 → 예외 확인`

---

## 📝 Commit

| Type | 의미 |
| --- | --- |
| `add` | 새로운 문제 풀이 추가 |
| `fix` | 오답 또는 오류 수정 |
| `refactor` | 풀이 로직이나 코드 구조 개선 |
| `docs` | README 등 문서 수정 |

```text
✨ add: 문제 풀이 추가
🐛 fix: 오답 수정
♻️ refactor: 풀이 개선
📝 docs: 문서 수정
```
